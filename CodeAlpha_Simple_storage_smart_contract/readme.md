# Simple Storage Smart Contract

## Project Overview

This project is developed as part of the CodeAlpha Blockchain Development Internship. The project focuses on creating a simple storage smart contract using Solidity and blockchain technology.

The main objective of this project is to understand the basics of smart contract development, data storage on blockchain, contract deployment, and interaction with blockchain networks.

## About Simple Storage Smart Contract

A smart contract is a program stored on a blockchain that automatically executes predefined instructions. In this project, a simple storage smart contract is created to store and retrieve a value securely on the blockchain.

The stored data is maintained in a decentralized environment and can be accessed through smart contract functions.

## Features

- Store data on blockchain
- Retrieve stored data
- Secure and transparent data management
- Decentralized storage system
- Smart contract-based operations
- Easy interaction with blockchain

## Technologies Used

- Solidity

## Smart Contract Functions

### Store Value

Allows users to save a value inside the smart contract.

### Retrieve Value

Allows users to view the previously stored value from the blockchain.

## Working of the Application

The Simple Storage Smart Contract is written using Solidity and deployed on an Ethereum-based blockchain network.

After deployment, users can interact with the contract using available functions. The user enters a value, and the smart contract stores it permanently on the blockchain. The stored value can later be retrieved by calling the retrieve function.

All interactions with the contract are recorded as blockchain transactions, ensuring transparency and security.

## Smart Contract Workflow

1. Create a Solidity smart contract.
2. Compile the contract using Remix IDE.
3. Deploy the contract on a blockchain network.
4. Enter a value using the storage function.
5. Store the value through a blockchain transaction.
6. Retrieve the stored value using the retrieve function.
